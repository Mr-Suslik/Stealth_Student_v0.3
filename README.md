# 🥷 Stealth_Student v0.3 (Window & Process Control)

A fast and lightweight Python utility (compiled to `.exe`) designed to manage window visibility and process controls on Windows. Instantly hide active windows, swap them using global hotkeys, or perform a quick close. Features a modern dark UI, system tray integration, automatic configuration saving, and multi-language support.

---

### ⚠️ IMPORTANT REQUIREMENT
> **Run as Administrator!**  
> To allow global hotkeys to intercept input and control windows across all system processes, **you MUST run `Stealth_Student.exe` as Administrator**.  
> *(Right-click `Stealth_Student.exe` -> "Run as administrator")*

---

### ✨ Key Features
- 🔄 **Window Swapping (Переключение окон):** One key hides the active window and shows the previously hidden one. A second key reverses the swap.
- ⚡ **Quick Close (Быстрое закрытие):** Instantly terminate or close designated active windows/processes.
- 🔽 **System Tray Integration:** Runs quietly in the background without cluttering your taskbar.
- 🌍 **4 Languages Supported:** Easily toggle between 4 interface languages.
- ⌨️ **Custom Hotkeys:** Rebind global hotkeys (e.g., F8 / F7) directly from the interface.

---

### ⚙️ Configuration File (`config`)
> The application automatically manages your preferences via a local **configuration file**.
- All settings (selected language, hotkeys, and app states) are automatically saved to a config file in the program folder.
- You don't need to reconfigure your hotkeys or language settings every time you launch the app.

---

### 🌐 Changing the Language
> **Note:** The default interface language is set to **Russian**.

To switch to English or another language:
1. Open the main window.
2. Click the **Language (Язык)** drop-down menu in the top-right corner.
3. Select your preferred language from the list (the setting will save to the config automatically).

---

### 🚀 Quick Start
1. Download `Stealth_Student.exe` (v0.3) from the repository/releases.
2. Right-click the `.exe` file and select **Run as Administrator**.
3. Configure your hotkeys (default: F8 / F7) and language.
4. Minimize the app to the system tray and focus on your work!
